# タスク仕様

## 目的

このタスクで実現したい利用者価値または解決したい問題を記載する。

## 背景

タスクが必要になった理由、現在の挙動、関連する意思決定を記載する。

## 対象範囲

- 変更してよい機能、画面、ファイル
- 必要なデータや設定の変更

## 対象外

- 今回は変更しない機能
- 後続タスクへ分離する事項

## 受け入れ条件

- [ ] 利用者から確認できる完了条件
- [ ] エラー時や境界値の期待動作
- [ ] 必要なドキュメントが更新されている
- [ ] `mise run verify` が成功する

## 制約・安全上の注意

- 互換性、性能、セキュリティ上の制約
- 実行してよい外部操作
- デプロイやリモートDB操作の要否

## 参考情報

- 関連Issue、Pull Request、設計資料
- 調査の起点となるファイルやURL

## 検証方法

`mise run verify` に加えて必要な手動確認があれば、手順と期待結果を記載する。
